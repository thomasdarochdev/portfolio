# Études de cas — scopes d'exemple

Document public pour clarifier **ce qui est livré**, pas des clients fictifs ni des avis inventés.

Ces scopes sont des **gabarits types** (Paris / remote). Prix indicatifs. Acompte standard : **40 %** à la commande, solde à la livraison / mise en prod.

## 1) Landing page — offre Pro (1 890 EUR)

**Objectif type**  
Page unique qui convertit une audience froide vers un appel / devis (service B2B ou local).

**Périmètre inclus**
- Brief 30–45 min + wireframe texte
- Next.js (App Router), responsive, SEO de base (title, meta, headings, OG)
- Sections : hero + CTA, preuves / méthode, offres ou pricing, FAQ, contact / formulaire
- Déploiement Vercel (ou hébergeur client)
- 1 round de retours majeurs + 1 polish

**Hors scope (sauf avenant)**  
Rédaction longue SEO, CRM complexe, multi-langue, design system complet.

**Délai indicatif** : 10–14 jours ouvrés.

**Artefact lié** : [`demos/landing-stub`](./demos/landing-stub) (structure technique).

## 2) Setup Grok OS — Complet (2 400 EUR)

**Objectif type**  
Mettre en place une orchestration agents (Chef OS + exécuteurs) pour ops freelance : repo, Slack, GitHub, routines quotidiennes.

**Périmètre inclus**
- Cartographie des workflows (inbox, suivi leads, preuves GitHub, relances)
- Configuration agents / règles / outils MCP utiles
- Intégrations GitHub (et Slack si compte dispo)
- Runbook court (comment relancer, quoi surveiller)
- Session handover + checklist go-live

**Hors scope**  
Automatisations marketing massives, scraping agressif, contournement de plateformes bloquées (ex. formulaire Codeur), bots X/Twitter (canal en pause).

**Délai indicatif** : 7–10 jours ouvrés.

**Variante Essentiel (1 200 EUR)** : setup minimal Chef OS + 1–2 workflows, sans intégrations avancées.

## 3) Commerce local Paris (690 EUR)

**Objectif type**  
Vitrine simple pour commerce de proximité (resto, salon, atelier) : trouver l'info, appeler, venir.

**Périmètre inclus**
- 1 page (ou 2) : accueil, horaires, adresse, services, CTA téléphone / Maps
- Mobile-first, perf correcte
- Textes courts fournis ou reformulés à partir du brief client
- Préparation fiche Google Business (checklist + champs prêts)
- Mise en ligne + passation accès

**Hors scope**  
E-commerce panier / paiement, réservation temps réel, photo pro, campagne Ads.

**Délai indicatif** : 3–5 jours ouvrés.
